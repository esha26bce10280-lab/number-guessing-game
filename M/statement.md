1. Problem Statement

Many beginners learning Python understand individual programming concepts such as variables, loops, conditions, and user input, but may find it difficult to combine them into a complete working application. The Number Guessing Game solves this by providing a simple interactive program where the computer generates a random number and the user tries to guess it. The program gives hints after each attempt, indicating whether the entered number is too high or too low, until the correct number is guessed.

2. Scope of the Project

The scope of this project is to develop a simple console-based Number Guessing Game using Python. The project includes random number generation, accepting user input, validating the input, comparing the guess with the secret number, providing hints, and displaying the final result. The current version does not require a database or internet connection. In the future, it can be expanded with difficulty levels, scoring, limited attempts, multiple rounds, and a graphical user interface.

3. Target Users

The main target users are students and beginners learning Python programming. The project helps learners understand how basic programming concepts can be combined to create a functional application. It can also be used by anyone who wants to play a simple guessing game for entertainment or practice.

4. High-Level Features
Random Number Generation: Generates a secret number randomly within a predefined range.
User Input: Allows the player to enter their guess.
Guess Comparison: Compares the user's guess with the secret number.
Helpful Hints: Displays whether the guess is too high or too low.
Attempt Tracking: Counts the number of attempts made by the player.
Input Validation: Handles invalid input and prevents the program from crashing.
Success Message: Displays a message when the player guesses the correct number.
Simple Interface: Provides an easy-to-use terminal/console-based interaction.
