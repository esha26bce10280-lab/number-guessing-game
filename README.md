🎯 Number Guessing Game

A simple and interactive Number Guessing Game built using Python.
The player has to guess a randomly generated number within a given range. The program provides hints after each guess until the correct number is found.

📌 Project Description

The Number Guessing Game is a beginner-friendly Python project designed to practice basic programming concepts such as:

Taking user input
Using conditional statements
Generating random numbers
Using loops
Comparing values
Displaying messages to the user

The game generates a random number, and the player keeps guessing until they find the correct number.

✨ Features
🎲 Generates a random number automatically
🔢 Allows the player to enter guesses
💡 Gives hints such as "Too High" or "Too Low"
✅ Displays a success message when the correct number is guessed
🔄 Uses a loop to allow multiple attempts
🖥️ Simple command-line interface
🐍 Beginner-friendly Python project
